# Kevin Li — Portfolio

Personal portfolio site: projects, experience, education and contact.

Live at **[kevinjli21.github.io/portfolio](https://kevinjli21.github.io/portfolio)**.

It's a single static page (`index.html`) with inline CSS and no build step. Pushing to `main` deploys it to GitHub Pages through `.github/workflows/static.yml`.

To update the résumé download, replace `assets/KevinLi_Resume.pdf`.
